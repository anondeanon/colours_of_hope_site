# Colours of Hope

Статична односторінкова вітрина благодійного конкурсу дитячого малюнка. Є шапка, герой, таймер, картки семи учасників і блок призів. Окремих сторінок немає: посилання в меню лише прокручують цю саму сторінку, кнопка «Голосувати» веде до карток, а вибір художника лише підсвічує картку.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте [http://127.0.0.1:43123](http://127.0.0.1:43123).
